# Archive

Material removed from `index.html` because nothing in the app used it. Kept intact.

- **lesson-phase-commentary.json** — each hexagram's commentary for each of the 20 Workbook phases (1,280 passages), plus the note that framed the oracle in each phase. Written for an earlier design in which the oracle's commentary changed with the reader's lesson; the oracle is now universal by design. Archived 25 Sept 2026.
- **unused-data.json** — the one-sentence line texts in the releasing voice (`sln`, six per hexagram, bottom line first), the classical source for each reading (`readingRoot`), the phase notes, and removed code (trigram table, line-position framework `LT`, `triRel`, `getThemeForDay`) verbatim. Archived 25 Sept 2026.

To bring any of it back, the texts can be pasted into the hexagram entries in `index.html` under the same field names.
